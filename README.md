# Cliff House at Canyon Lake

Informational website for the Cliff House waterfront vacation rental with a synchronized Airbnb availability calendar.

## Setup

1. Run `npm install`.
2. Copy `.env.example` to `.env.local`.
3. Add the owner's Airbnb calendar export/iCal URL.
4. Run `npm run dev`.

The public listing is the only booking destination; this website does not collect payments.

## Required before launch

- Add `AIRBNB_ICAL_URL` to the deployment environment variables.
- Add the owner's preferred contact details and domain.
